DSH 翻译

所有推理都在 DSH 的本机 NPU 上完成，网页内容不会离开这台电脑或内网。

连接

DSH 的 NPU 插件在工作时，点下面的按钮就能自动找到它；找不到再手填地址。

未连接 点右边自动搜索
DSH 面板上显示的是 http://host:端口/v1，直接粘上去也行。 面板绑在局域网时本机 127.0.0.1 可能打不通，填局域网地址并在授权框点「允许」。
DSH 开了 API token 时填同一个值，会以 Authorization: Bearer <token> 发送。
每行一个网段前缀（三段，例如 192.168.1）。 「一键连接」会先试回环和本机网卡；都不通时按这个网段扫 DSH 端口（47300）。 留空则自动扫常见网段。
DSH 的「模型名」就是角色：translate 是专职翻译模型，最推荐； chat 是通用对话模型。留空会自动挑。
